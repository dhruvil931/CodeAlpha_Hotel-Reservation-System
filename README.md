# 🏨 Hotel Reservation System

A Java-based Hotel Reservation System that allows users to search rooms, book rooms, cancel reservations, and manage hotel bookings efficiently.

## 🚀 Features

- Room booking system
- Room categorization
  - Standard
  - Deluxe
  - Suite
- Reservation management
- Booking cancellation
- Payment simulation
- Customer booking details
- Room availability tracking

## 🛠️ Tech Stack

- Java
- OOP Concepts
- Collections Framework
- MySQL

## ⚙️ Functionalities

### Room Booking
- Search available rooms
- Book rooms based on category

### Reservation Management
- Store reservation details
- View customer bookings

### Cancellation System
- Cancel reservations
- Update room availability

### Payment Simulation
- Simulate booking payment process

## ▶️ How to Run

1. Clone the repository
2. Open project in IntelliJ / VS Code
3. Compile and run `Main.java`
